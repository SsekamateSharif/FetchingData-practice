# Pokémon API Data Fetching

A JavaScript project that fetches Pokémon data from the PokéAPI and displays the retrieved information.

## Features

* Fetches Pokémon data using the Fetch API
* Handles asynchronous operations with Promises
* Implements the `async/await` approach
* Converts API responses into JSON
* Accesses and displays Pokémon information and sprites

## Technologies

* JavaScript
* Fetch API
* Promises
* Async/Await
* PokéAPI
